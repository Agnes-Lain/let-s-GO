隐私政策

Let's GO 不收集任何个人信息。

  • 没有账号：无需注册或登录。
  • 没有广告。
  • 没有数据分析，没有跟踪：应用里没有任何统计、广告或崩溃上报工具。
  • 不使用网络：应用完全离线运行，不向任何服务器发送数据。
  • 数据只在你的设备上：学习进度和设置（语言、声音、减少动画）只保存在你的手机里。
  • 卸载即删除：卸载应用时，这些数据会一并删除。
  • 我们不与任何人分享数据，因为我们没有任何数据。

Privacy policy

Let's GO collects no personal data.

  • No account: nothing to sign up for or log in to.
  • No advertising.
  • No analytics and no tracking: the app contains no analytics, advertising or crash-reporting tools.
  • No network use: the app works fully offline and sends nothing to any server.
  • Your data stays on your device: your lesson progress and settings (language, sound, reduce motion) are stored only on your phone.
  • Deleting the app deletes the data: when you uninstall the app, this data is removed too.
  • We share no data with anyone, because we have none.

This web page is hosted by GitHub Pages; GitHub may log technical data about visitors (such as IP addresses). See the GitHub privacy statement.

Politique de confidentialité

Let's GO ne collecte aucune donnée personnelle.

  • Pas de compte : aucune inscription ni connexion.
  • Pas de publicité.
  • Pas d'analyse, pas de suivi : l'app ne contient aucun outil de statistiques, de publicité ou de rapport de plantage.
  • Pas de réseau : l'app fonctionne entièrement hors ligne et n'envoie rien à aucun serveur.
  • Vos données restent sur votre appareil : votre progression et vos réglages (langue, son, réduction des animations) sont enregistrés uniquement sur votre téléphone.
  • Supprimer l'app supprime les données : en désinstallant l'app, ces données sont effacées.
  • Nous ne partageons aucune donnée, puisque nous n'en avons aucune.

Cette page est hébergée par GitHub Pages ; GitHub peut enregistrer des données techniques sur les visiteurs (par exemple l'adresse IP). Voir la déclaration de confidentialité de GitHub.
